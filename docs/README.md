# Architecture Decision Records (ADR)

This directory contains all Architecture Decision Records (ADR) for NovaCommerce Backend.

An ADR documents important architectural decisions made during the project, including the context, alternatives considered, the final decision, and its consequences.

The goal is to preserve the reasoning behind technical decisions so future contributors can understand why a particular approach was chosen.
